# Project stories

- [Dorky Commander (ESP32-DualCAN)](https://opencartools.github.io/ESP32-DualCAN/) — open source S3XY Commander alternative on an ESP32-C6: dual CAN, BLE WebUI, OTA and a Molex connector compatible with Enhauto harnesses.
- [BMW E-series CAN reverse engineering](https://bmw-e8x-e9x.github.io/opendbc/) — opendbc port and analysis for BMW E8x/E9x chassis.
- [StepperServoCAN](https://dzid26.github.io/StepperServoCAN/) — closed loop stepper motor controller with CAN bus support, firmware and hardware.
