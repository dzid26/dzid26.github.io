# Project stories

## Projects

- **[Dorky Commander (ESP32-DualCAN)](https://opencartools.github.io/ESP32-DualCAN/)** — open source S3XY Commander alternative on an ESP32-C6: dual CAN, BLE WebUI, OTA, and a Molex connector compatible with Enhauto harnesses.
- **[TeslaBatteryBLE](https://opencartools.github.io/TeslaBatteryBLE/)** — Android app that tracks Tesla battery statistics directly over Bluetooth LE, using an enrolled vehicle key.
- **[StepperServoCAN](https://dzid26.github.io/StepperServoCAN/)** — closed loop stepper motor controller with CAN bus support; open source firmware and hardware.
- **[BMW E-series opendbc](https://bmw-e8x-e9x.github.io/opendbc/)** — CAN signal definitions and reverse engineering work for BMW E8x/E9x.

## Forks and hardware

- [opendbc](https://github.com/dzid26/opendbc) — fork of sunnypilot/opendbc with a **Tesla cooperative steering** implementation: blends driver and system torque, with torque-to-angle/ramp mapping and LKAS compensation.
- [OBD-C_Y_splitter](https://github.com/dzid26/OBD-C_Y_splitter) — OBD-C Y splitter hardware.
- [Batman-dock](https://github.com/dzid26/Batman-dock) — mount for Konik A1 v0.5 with pins.
- [JLC2KiCad_gui](https://github.com/dzid26/JLC2KiCad_gui) — KiCad component library generator for JLCPCB/EasyEDA parts (fork).
- [openpilot](https://github.com/BMW-E8x-E9x/openpilot) — fork of commaai/openpilot used for driving stack experiments.
